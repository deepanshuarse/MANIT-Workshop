# DSA Workshop – MANIT

This repository contains my learning, practice, and solutions from the **DSA (Data Structures and Algorithms) Workshop at MANIT**.

The workshop introduced the **fundamentals of DSA** and focused on understanding basic problem-solving techniques and algorithms. This is the beginning of my DSA journey, and I will continue adding more topics and problems as I learn.

---

## 📚 Topics Covered

### 1. Two Pointers
- Understanding the two-pointer technique
- Using two pointers to solve array and string problems
- Optimizing solutions by reducing unnecessary iterations
- Working with left and right pointers

### 2. Recursion
- Understanding the concept of recursion
- Base cases and recursive cases
- Recursive function calls
- Solving basic problems using recursion
- Understanding how recursive calls work

### 3. Binary Search
- Understanding binary search
- Searching efficiently in sorted arrays
- Using `left`, `right`, and `mid` pointers
- Reducing the search space at every step
- Understanding the time complexity of binary search
